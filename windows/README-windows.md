# csqtt-win: Руководство пользователя (Windows)

Нативный Windows-клиент csqtt (порт csqtt 2.5.0), создающий защищённый туннель поверх протоколов TURN/RTP с маскировкой трафика под голосовые и видеозвонки (VK Calls).

---

## 1. Что это

**csqtt-win** переносит функциональность Android-клиента csqtt на платформу Windows. Программа состоит из трёх основных компонентов:

- **Ядро (`client.exe`)**: скомпилированное ядро `rust-client` с патчами под Windows. Работает через виртуальный сетевой драйвер Wintun, изолирует собственные сетевые сокеты от туннеля (`IP_UNICAST_IF`) и контролируется родительским процессом.
- **Системная служба (`csqtt-svc.exe`)**: фоновая служба Windows (запускается от учетной записи `NT AUTHORITY\SYSTEM`). Управляет сетевым адаптером Wintun, IP-адресами, маршрутизацией (маршруты `0.0.0.0/1` и `128.0.0.0/1`), политиками DNS (NRPT для защиты от утечек), аварийным восстановлением сети после сбоев и хранилищем секретов.
- **Интерфейс пользователя (`csqtt.exe`)**: консольная утилита (CLI) и значок системного трея (Tray). Запускается от имени обычного пользователя без запросов UAC и взаимодействует со службой через защищённый именованный канал (Named Pipe `\\.\pipe\csqtt-win`).

---

## 2. Системные требования

- **Операционная система**: Windows 10 (версия 2004 / сборка 19041 или новее) или Windows 11.
- **Архитектура**: x86_64 (64-бит).
- **Среда выполнения WebView2**: Microsoft Edge WebView2 Runtime (Evergreen Runtime; предустановлен в Windows 11 и актуальных версиях Windows 10).
- **Драйвер Wintun**: библиотека `wintun.dll` (должна располагаться рядом с исполняемыми файлами).
- **Права администратора**: требуются только для разовой установки/удаления службы (`csqtt-svc.exe install` / `uninstall`) и запуска службы через `sc start`. Повседневное использование (`csqtt.exe` CLI и трей) работает **без прав администратора**.

## 3. Установка

### Вариант А: Установщик (Setup)
Запустите файл инсталлятора от имени Администратора. Мастер установки скопирует бинарные файлы, зарегистрирует и запустит службу `csqtt-win`, а также добавит каталог программы в переменную окружения `PATH`.

### Вариант Б: Портативный архив (Portable ZIP)
1. Распакуйте архив в постоянный каталог (например, `C:\Program Files\csqtt-win` или `C:\Tools\csqtt-win`).
2. Убедитесь, что все файлы находятся в одной папке:
   - `csqtt-svc.exe` — служба Windows;
   - `csqtt.exe` — консольный клиент и трей;
   - `client.exe` — сетевое ядро;
   - `wintun.dll` — драйвер сетевого адаптера.
3. Откройте командную строку (`cmd.exe`) или PowerShell **от имени Администратора**.
4. Перейдите в каталог с распакованными файлами и зарегистрируйте службу:
   ```cmd
   csqtt-svc.exe install
   ```
5. Запустите службу:
   ```cmd
   sc start csqtt-win
   ```
   *Служба регистрируется с автоматическим типом запуска (`AutoStart`) и настроенным автоматическим перезапуском при сбоях (через 5, 10 и 20 секунд).*
6. (Рекомендуется) Добавьте путь к каталогу в системную переменную `PATH`, чтобы запускать `csqtt` из любой папки.

## 4. Первый запуск

1. **Импорт конфигурации**  
   Импортируйте профиль по ссылке:
   ```cmd
   csqtt import csqtt://...
   ```
   Либо из JSON-файла экспорта (полученного из Android-версии csqtt):
   ```cmd
   csqtt import config.json
   ```

2. **Проверка состояния**  
   ```cmd
   csqtt status
   ```

3. **Подключение**  
   ```cmd
   csqtt connect
   ```

4. **Отключение**  
   ```cmd
   csqtt disconnect
   ```

5. **Системный трей и глобальная горячая клавиша**  
   Для удобного управления туннелем в фоновом режиме запустите трей:
   ```cmd
   csqtt tray
   ```
   - **Иконка в трее**: отображает текущий статус соединения во всплывающей подсказке (`отключено`, `подключение...`, `подключено`, `служба не запущена`).
   - **Контекстное меню** (правый клик): «Подключить», «Отключить», «Показать логи» (открывает окно с журналом), «Выход».
   - **Быстрое переключение**: двойной клик левой кнопкой мыши по иконке переключает подключение/отключение.
   - **Глобальная горячая клавиша**: комбинация **`Ctrl + Alt + V`** переключает подключение (Connect/Disconnect) из любого активного окна Windows.

## 5. Команды CLI (`csqtt.exe`)

| Команда | Описание | Пример использования |
|---|---|---|
| `connect` | Подключиться с сохранёнными настройками активного профиля | `csqtt connect` |
| `disconnect` | Отключить VPN-соединение | `csqtt disconnect` |
| `status` | Показать состояние туннеля (статус, IP, DNS, число воркеров, переданный трафик) | `csqtt status` |
| `logs [-f] [-n <число>]` | Просмотр журнала событий. `-n` задаёт число строк (по умолчанию 100), `-f` (`--follow`) включает непрерывный вывод | `csqtt logs -f`<br>`csqtt logs -n 50` |
| `import <ссылка\|файл>` | Импортировать конфигурацию из ссылки `csqtt://` или файла JSON | `csqtt import csqtt://ey...`<br>`csqtt import backup.json` |
| `export [--secrets] [файл]` | Экспортировать конфигурацию в формате JSON (совместимом с Android). Опция `--secrets` (`-s`) включает защищённые пароли/токены. При указании файла выводит в него, иначе — в stdout | `csqtt export out.json`<br>`csqtt export -s` |
| `settings get [ключ]` | Получить все настройки в формате JSON или значение отдельного ключа | `csqtt settings get`<br>`csqtt settings get peer` |
| `settings set <ключ> <значение>` | Записать значение параметра конфигурации (строка или JSON-значение) | `csqtt settings set workers_per_hash 18`<br>`csqtt settings set excluded_apps "game.exe"` |
| `secret set <ключ> <значение>` | Записать защищённый секрет в хранилище DPAPI | `csqtt secret set connection_password_encrypted "pass123"` |
| `tray` | Запустить значок в системном трее Windows с горячей клавишей `Ctrl+Alt+V` | `csqtt tray` |
| `help` | Показать встроенную справку по командам | `csqtt help` |

### Статус нереализованных команд:
- **`vk-login`**: команда отдельного входа через браузер в CLI **не реализована** (в разработке; графический модуль авторизации `vk_auth.rs` на базе WebView2 находится в процессе интеграции). Авторизация VK на текущий момент настраивается через импорт ссылки с токеном или команду `csqtt secret set vk_access_token_encrypted <токен>`.
- **`apps add / remove`**: отдельные команды управления приложениями в CLI **не реализованы** (в разработке). Добавление и удаление исключений выполняется через параметр настроек `excluded_apps` (см. раздел «Исключения приложений»).

## 6. Исключения приложений (Split Tunneling)

csqtt-win поддерживает выборочный пропуск трафика отдельных приложений мимо VPN-туннеля со своего реального IP-адреса.

### Настройка исключений
Имена исполняемых файлов (.exe) задаются через запятую в параметре профиля `excluded_apps`:
```cmd
csqtt settings set excluded_apps "telegram.exe,discord.exe,game.exe"
```

Просмотр текущего списка исключений:
```cmd
csqtt settings get excluded_apps
```

### Как это устроено
Ядро сетевого клиента анализирует открытые локальные порты сетевых подключений через Windows API (`GetExtendedTcpTable` / `GetExtendedUdpTable`), определяет соответствующий процесс (PID -> имя исполняемого файла) и направляет трафик процесса в обход виртуального Wintun-адаптера через физический интерфейс (`direct_relay`). Установка сторонних драйверов WFP не требуется.

*Примечание: UWP-приложения из Microsoft Store в текущей версии не поддерживаются.*

## 7. Капча и вход в VK (Окна WebView2)

При подключении через VK Calls или автоматическом получении хешей сервис может запросить решение капчи:
- **Автоматическая капча**: фоновый процесс решения запускается внутри скрытого движка WebView2.
- **Интерактивная капча**: при необходимости вмешательства пользователя выводится окно браузера WebView2 для ручного ввода символов или прохождения проверки.
- **Раздельные профили**: кэш, куки и данные авторизации хранятся изолированно в `%LOCALAPPDATA%\csqtt-win\webview2\` (отдельные каталоги для решения капчи и для авторизации в профиле VK).
- *Примечание*: окно решения капчи через WebView2 в CLI и трее находится в процессе финализации; при возникновении запроса трей отображает системное предупреждение.

## 8. Логирование

- **Просмотр в реальном времени:**
  ```cmd
  csqtt logs -f
  ```
- **Просмотр последних N строк:**
  ```cmd
  csqtt logs -n 100
  ```
- **Логи из трея:**
  В контекстном меню значка трея выберите пункт **«Показать логи»** — откроется консоль с живым журналом.
- **Файлы журналов на диске:**
  Служба сохраняет журналы в общесистемном каталоге:
  `%ProgramData%\csqtt-win\logs\` (по умолчанию `C:\ProgramData\csqtt-win\logs\`).

## 9. Деплой сервера

Установка сервера csqtt на VPS по SSH (как вкладка «Деплой» в Android):

```
csqtt deploy --host <IP> [--port 22] [--user root] [--key <файл ключа>] [--sudo] [--docker]
             [--peer-port 46000] [--web-port 46002] [--web-login <логин>] [--assets <папка>]
csqtt undeploy --host <IP> ...      удалить сервер
csqtt update-check                  проверить новую версию клиента
```

- Пароль SSH берётся из переменной `CSQTT_SSH_PASSWORD`, иначе запрашивается в консоли (ввод виден).
- Пароли туннеля и веб-панели: `CSQTT_MAIN_PASSWORD` / `CSQTT_WEB_PASSWORD` или генерируются автоматически.
- Ключ сервера проверяется по принципу TOFU: при первом подключении спросит подтверждение, отпечатки хранятся в `%LOCALAPPDATA%\csqtt-win\known_hosts.json`.
- Нужны бинарники сервера (`csqtt-linux-amd64` и др.) в папке `server\` рядом с `csqtt.exe` (или `--assets`). Собираются `rust-server/build_linux.bat`; в zip пока не входят.
- После успешного деплоя адрес и пароль автоматически записываются в настройки службы.

## 10. Удаление

### Удаление при использовании инсталлятора
Удалите программу через стандартное меню Windows «Установка и удаление программ» (Параметры -> Приложения -> Установленные приложения -> csqtt-win -> Удалить).

### Удаление Portable-версии
1. Запустите командную строку от имени **Администратора**.
2. Перейдите в каталог программы и остановите/удалите службу:
   ```cmd
   csqtt-svc.exe uninstall
   ```
3. Выполните полную очистку сетевых хвостов:
   ```cmd
   csqtt-svc.exe cleanup
   ```
4. Удалите каталог с программой и каталог сохранённых данных `%ProgramData%\csqtt-win`.

## 11. Диагностика и устранение неполадок

### 1. «Служба не запущена» / «Не удалось подключиться к службе csqtt-svc»
- Проверьте состояние службы:
  ```cmd
  sc query csqtt-win
  ```
- Если служба остановлена, запустите её (в консоли администратора):
  ```cmd
  sc start csqtt-win
  ```
- Если служба не найдена, переустановите её:
  ```cmd
  csqtt-svc.exe install
  ```
- Убедитесь, что файлы `client.exe` и `wintun.dll` находятся в том же каталоге, что и `csqtt-svc.exe`.

### 2. Нет доступа в интернет после сбоя или аварийного выключения
- При внезапном падении системы или аварийном завершении службы в таблице маршрутизации могут остаться разделяющие маршруты (`0.0.0.0/1` и `128.0.0.0/1`) или правило перехвата DNS (NRPT).
- **Решение**: запустите консоль от имени Администратора и выполните:
  ```cmd
  csqtt-svc.exe cleanup
  ```
  Команда принудительно удаляет оставшиеся маршруты из журнала `routes_journal.json`, сбрасывает правила NRPT в реестре и удаляет адаптер Wintun, восстанавливая штатное сетевое подключение.

### 3. Ошибка отсутствия WebView2
- Если при входе в VK или капче возникает ошибка об отсутствии браузерного движка, установите официальный пакет **Microsoft Edge WebView2 Evergreen Runtime** с сайта Microsoft:
  `https://developer.microsoft.com/ru-ru/microsoft-edge/webview2/`

### 4. Ошибка авторизации (неверный пароль или хеши)
- Проверьте вывод команды `csqtt status`. При неверном пароле статус туннеля отобразит причину ошибки (например, `Ошибка (🔒 Неверный пароль подключения. Воркеры остановлены.)`).
- Проверьте журнал последних событий через `csqtt logs -n 50`.

## 12. Хранение данных и шифрование DPAPI

### Расположение файлов
Все рабочие файлы и настройки хранятся в общесистемном каталоге **`%ProgramData%\csqtt-win\`** (обычно `C:\ProgramData\csqtt-win\`):

- `settings.json` — конфигурация профилей, параметры портов, списки исключённых приложений и доменов.
- `secrets.json` — зашифрованные учётные данные (пароль туннеля, токены VK, ключи SSH).
- `host_keys.json` — база доверенных отпечатков ключей серверов (TOFU).
- `routes_journal.json` — журнал добавленных сетевых маршрутов (используется для автоматической очистки при сбоях).
- `logs\` — каталог текстовых журналов работы.

Пользовательские данные браузерного движка WebView2 сохраняются в папке пользователя:
- `%LOCALAPPDATA%\csqtt-win\webview2\`

### Защита секретов через Windows DPAPI
Конфиденциальные данные никогда не хранятся в открытом виде. Значения в `secrets.json` шифруются стандартным интерфейсом Windows Data Protection API (**DPAPI** — функция `CryptProtectData`) со следующими параметрами:
- Область действия: **`CRYPTPROTECT_LOCAL_MACHINE`** (уровень компьютера с флагом `CRYPTPROTECT_UI_FORBIDDEN`), что позволяет системной службе, работающей под учетной записью SYSTEM, расшифровывать секреты независимо от активного пользователя и после перезапуска службы.
- Дополнительная энтропия: постоянная строка `csqtt-win`.
- Зашифрованные данные сериализуются в шестнадцатеричную строку (hex). Доступ к расшифровке имеет только служба на данной конкретной системе Windows.
