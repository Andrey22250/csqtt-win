# csqtt-win 0.1.1

Исправления Windows-клиента без смены архитектуры и протокола ядра.

- Маршрутизация: переключатели зон и шаблона, исключения «всегда через VPN», поддержка `!example.ru` для домена и поддоменов. Исключение приоритетнее автоматических правил и кэша прямых IP.
- Сохранение: последовательные обновления настроек без потери полей; флаги не сбрасываются при смене режима списка.
- Таймер: отсчёт от времени подключения службы, восстановление после открытия окна и задержек интерфейса.
- Навигация: кнопки не пересоздаются при обновлении статуса, нажатие не теряется.
- Выбор процессов: строки не сжимаются, длинные пути переносятся, есть поиск, пустое состояние и повтор загрузки после ошибки.
- Диалоги: Escape закрывает верхнее окно, фокус возвращается в родительское; повторное закрытие безопасно.

## Проверка

385 Windows-тестов прошли, 2 пропущены. Ядро: 372 прошли, 10 пропущены. Браузерные регрессии проверяют настройки, маршрутизацию, таймер, клики между обновлениями статуса, список из 80 процессов, вложенные окна, светлую/тёмную темы и ширину 360/520 пикселей. Пользователь подтвердил работающее подключение после предыдущего этапа исправлений.

## Файлы

- `dist/csqtt-win-0.1.1-setup.exe` — установщик.
- `dist/csqtt-win-0.1.1-windows-x64.zip` — портативный архив.
- Рядом лежат контрольные суммы SHA-256.

Установщик обновляет программу и службу. Установка прервёт активный VPN-сеанс. Перед обновлением сохраните необходимые данные; настройки в ProgramData не удаляются при обычном обновлении. Сам установщик в ходе подготовки релиза не запускался на рабочей установке.
